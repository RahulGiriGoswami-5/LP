# Interactive Animated Login Page

A responsive and interactive login / sign-in interface featuring animated SVG characters that react dynamically to user input (such as email entry, password typing, error states, and mouse cursor movements).

## 🚀 Features

- **Dynamic Interactive Characters**: Custom vector characters (`pink-dome`, `trumpet`, `teal-fluffy`, `blue-circle`) that follow your cursor, look away during password entry, and display emotional reactions.
- **Dual Authentication Modes**: Seamless toggle between **Sign In** and **Log In** states with smooth field transitions.
- **Responsive Layout**: Designed for seamless viewing across desktop, tablet, and mobile screens.
- **Pure Web Technologies**: Built cleanly with Vanilla HTML5, CSS3, and modern JavaScript.

## 📁 Project Structure

```
├── index.html            # Main markup and layout
├── style.css             # Styling, layout grids, and responsive media queries
├── app.js                # Character animations, state management, and form logic
└── characters/           # Modular SVG assets
    ├── blue-circle.svg
    ├── pink-dome.svg
    ├── teal-fluffy.svg
    └── trumpet.svg
```

## 🛠️ Getting Started

Open `index.html` in your web browser or serve it using any local static file server:

```bash
npx http-server -p 8080
```
